# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

- Preferred: use GitHub's **Report a vulnerability** button (Security tab → Advisories) on the affected repository.
- Or email **mahdi.mortazavi.135@gmail.com** with steps to reproduce.

You will get a first reply within 72 hours. Confirmed issues are fixed as fast as possible and credited in the release notes unless you prefer to stay anonymous.

## Supported versions

Only the latest release of each project receives security fixes.
